1. 概述

1.1 vJASS 与 JASS 的关系

vJASS 是 JASS 的编译期扩展，由 Vexorian 的 JassHelper 预处理器实现：地图保存时把 vJASS 代码翻译回纯 JASS，再交给游戏执行。官方手册的定位原文：

  • JassHelper is a compiler for the vJass language extension which includes structs, libraries, textmacros and more.
  • vJASS 并非完全的 OOP——手册明确说明它没有传统意义上的继承对象模型，对象不叫 class 而叫 struct；多态由 interface 提供。
  • vJASS 1.0.0 之后语法保持冻结，不再新增语法结构。

因此，vJASS 的一切能力都受 JASS 本身限制：数组上限 8191、struct 实例上限 8190、无真正指针、字符串不可变等。

3. 词法与基础增强

3.1 嵌套块注释 vJASS

在 JASS 的行注释 // 之外，vJASS 增加 /* ... */ 块注释，且支持嵌套；注释在预处理后从脚本中删除。

delimited comments
/* 块注释可以 /* 嵌套 */ 继续 */
function test takes nothing returns nothing
    call Something( /*5*/ 66) // 行内注释也合法
endfunction

3.2 全局声明自由 vJASS

globals 块可以写在地图脚本任意位置（包括普通触发器里），jasshelper 会把所有全局块合并上移到脚本顶部。约束：

  • 初始值只能是编译期常量：null、数字、true/false、字符串、十六进制等；
  • 不允许函数调用、native 调用，也不允许引用其他全局变量（无法控制合并后的声明顺序）；
  • 常量建议大写，JASS 惯例 udg_ 前缀保留给 GUI 全局变量。
globals freedom
function something takes nothing returns nothing
    set somearray[SOMETHING_INDEX]=4
endfunction

globals
    constant integer SOMETHING_INDEX = 45
    integer array somearray
endglobals
注意同域的 private/public 全局变量必须先声明后使用，否则 jasshelper 会把它当普通未声明标识符处理。

3.3 native 自由声明 vJASS 0.9.I.0+

native 声明本必须紧跟脚本全局区，vJASS 允许写在任意位置并自动归位；若与 common.j 重复声明会被自动删除。

native freedom
native GetUnitGoldCost takes integer unitid returns integer

function test takes nothing returns nothing
    call BJDebugMsg("A footman costs : "+I2S( GetUnitGoldCost('hfoo') )+" gold coins" )
endfunction

3.4 局部变量遮蔽修复 vJASS 0.9.K.0+

原版 JASS 中局部变量与全局同名会引发不可预测的问题（1.24 补丁前甚至会把整个脚本变成大小写不敏感）。vJASS 预处理阶段会对冲突的局部变量加 l__ 前缀模拟正确的遮蔽，因此局部变量可以放心与任何全局同名。

标识符约定预处理器生成的名字使用双下划线（如 scopename__x），自己手写的标识符应避免使用连续双下划线，便于阅读编译产物时区分。

4. Library 与 Scope

4.1 library 库

WE 保存地图时触发器顺序不可控，函数可能被先用后声明。library 把一组代码移动到地图脚本顶部，并按依赖关系自动排序：

library · 依赖排序
library C requires A, B, D
    function Cfun takes nothing returns nothing
        call Afun()
        call Bfun()
        call Dfun()
    endfunction
endlibrary

library D
    function Dfun takes nothing returns nothing
    endfunction
endlibrary

library B requires A
    function Bfun takes nothing returns nothing
        call Afun()
    endfunction
endlibrary

library A
    function Afun takes nothing returns nothing
    endfunction
endlibrary

编译后脚本顶部顺序为 A → D → B → C（依赖先入）。规则清单：

  • 库名大小写敏感；
  • requires、needs、uses 三词等价（官方建议只用 requires）；
  • 依赖出现循环（直接或间接）直接报语法错误；
  • library 不可嵌套，也不能写在 scope 内部；
  • 0.9.B.0 起，globals 块的合并顺序也由依赖关系保证。

initializer：库可以指定初始化函数，经 ExecuteFunc 在独立线程执行（防止 init 线程崩溃波及主初始化）：

library initializer
library A initializer InitA requires B

    function InitA takes nothing returns nothing
        call StoreInteger(B_gamecache , "a_rect" , Rect(-100.0 , 100.0 , -100.0 , 100.0 ) )
    endfunction

endlibrary

library B initializer InitB
    globals
        gamecache B_gamecache
    endglobals

    function InitB takes nothing returns nothing
        set B_gamecache=InitGameCache("B")
    endfunction
endlibrary
  • initializer 必须是 takes nothing 的函数；
  • 执行顺序 = 库的排序顺序：B 排在 A 前，则 B 的 initializer 先执行。

4.2 library_once 与 optional 依赖

  • library_once：与 library 相同，但同名库重复声明时第二次声明被忽略而不报错——专为文本宏组合设计；
  • optional 依赖 0.9.Z.0+：依赖的库不存在时不报错，库仍会被排到该依赖之后（存在时）；
  • 每个 library NAME 同时生成一个编译期布尔常量 LIBRARY_NAME，供 static if 判断库是否存在。
optional 依赖 + LIBRARY_ 常量
library OptionalCode requires optional UnitKiller
    function fun takes nothing returns nothing
        local unit u = GetTriggerUnit()
        static if DO_KILL_LIB and LIBRARY_UnitKiller then
            call UnitKiller(u)
        else
            call KillUnit(u)
        endif
    endfunction
endlibrary

4.3 scope 作用域

不需要移动到脚本顶部、只想要命名空间与封装时使用 scope：

scope + private
scope GetUnitDebugStr

    private function H2I takes handle h returns integer
        return h
        return 0
    endfunction

    function GetUnitDebugStr takes unit u returns string
        return GetUnitName(u)+"_"+I2S(H2I(u))
    endfunction

endscope
  • scope Name initializer InitFn 同样支持 initializer，但用的是普通 call（非 ExecuteFunc）——重量级初始化请用 library 或在 initializer 内自行 ExecuteFunc；
  • scope 可以嵌套（scope 套 scope、library 套 scope），子作用域视为父作用域的 public 成员；
  • 引用嵌套子作用域的 public 成员需要逐级前缀：Parent_Child_member；
  • 同一层级不能重名 scope；不同父作用域的子 scope 可以同名；
  • 嵌套子作用域不能重复声明父作用域已声明的 private/全局名（解析器限制，与声明先后有关）。

4.4 private / public 封装

修饰编译期处理可见性
private改名为 Name__随机数__仅所在 scope/library 内部可用，外部无法用前缀 hack 访问
public改名为 Name_成员名内部直接用原名；外部必须加 Name_ 前缀
（无修饰）保持原名全脚本可见（不推荐，易冲突）
public 成员与命名前缀
library cookiesystem
    public function ko takes nothing returns nothing
        call BJDebugMsg("a")
    endfunction

    function thisisnotpublicnorprivate takes nothing returns nothing
        call ko()                 // 内部：原名即可
        call cookiesystem_ko()    // 带前缀也合法
    endfunction
endlibrary

function outside takes nothing returns nothing
    call cookiesystem_ko()        // 外部：必须带前缀
endfunction
ExecuteFunc 特例public 函数用字符串调用时无论在内外都必须写全名 ExecuteFunc("cookiesystem_ko")；写原名会崩溃。private 成员则根本无法用字符串引用，除非借助 SCOPE_PRIVATE（下节）。
InitTrig 特例若把触发器自动生成的 InitTrig 函数声明为 public，则编译名是 InitTrig_ScopeName（而非 ScopeName_InitTrig），可直接对接 WE 触发器命名惯例。

4.5 SCOPE_PREFIX / SCOPE_PRIVATE

scope/library 内部可用的两个字符串常量，用于 ExecuteFunc、real 值事件等需要函数名字符串的场合：

SCOPE_PREFIX / SCOPE_PRIVATE
scope test
    private function kol takes nothing returns nothing
        call BJDebugMsg("...")
    endfunction

    function lala takes nothing returns nothing
        call ExecuteFunc(SCOPE_PRIVATE+"kol")
    endfunction
endscope

4.6 keyword 前置声明

scope 内的 private/public 成员不能先用后声明。当两个函数互相递归又要都保持 private 时，需要 keyword 先声明占位：

keyword
scope myScope

   private keyword B   // 先把 B 声明为本 scope 的私有成员

   private function A takes integer i returns nothing
       if(i!=0) then
           return B.evaluate(i-1)*2   // B 尚未定义，但 keyword 已生效
       endif
       return 0
   endfunction

   private function B takes integer i returns nothing
       if(i!=0) then
           return A(i-1)*3
       endif
       return 0
   endfunction

endscope

5. 变量与数组系统

5.1 定长数组 sized arrays

globals 数组可指定长度（[长度] 可用常量表达式），目的有二：突破 8191 上限、获得 .size 字段：

sized arrays
globals
    integer array myArray [500]
    integer array big      [9000]      // 突破 8191
    constant integer Q= 60000
    integer array huge     [Q]         // 用常量
endglobals

function test takes nothing returns nothing
    local integer i=0
    call BJDebugMsg(I2S(myArray.size))   // 输出 500
    loop
        exitwhen i>=myArray.size
        set myArray[i]=i
        set i=i+1
    endloop
endfunction

struct 的静态数组成员同样可用：static integer A[10000]。

5.2 二维数组

声明形式 类型 array 名字[宽][高]，本质是用乘法折算的一维数组：

  • 实际尺寸 = 宽 × 高，受 ≈40800 上限约束；
  • 尺寸 > 8191 时访问退化为函数调用（慢），并会生成多个实际数组；
  • 字段：.size（宽×高）、.width、.height；
  • 仅支持二维；局部变量不允许定长/二维数组。
2D arrays
globals
   integer array mat1 [10][20]
endglobals

function test takes nothing returns nothing
    call BJDebugMsg(I2S(mat1.size))     // 200 (10 * 20)
    set mat1[0][1] = 2
    call BJDebugMsg( I2S( mat1[0][1] ) ) // 2
endfunction

5.3 动态数组（type 声明）

动态数组是"可动态分配的数组类型"，语法与 struct 似：

dynamic arrays
type arsample extends integer array[8]

function test takes nothing returns arsample
 local arsample r=arsample.create()
 local integer i=0
     loop
         exitwhen i==arsample.size   // 数组类型的尺寸常量
         set r[i]=i
         set i=i+1
     endloop
 return r
endfunction
  • 每个动态数组类型共享 8190 个索引；尺寸 100 的类型最多 81 个实例，超限时 create() 返回 0（debug 模式自动告警）；
  • 可套娃：type iar extends integer array[3] → type iar_ar extends iar array[3]；
  • 动态数组可作为 struct 实例成员（成员类型是动态数组，自己 create/destroy）——这是不定长数组成员的唯一替代；
  • 增强存储：type X extends integer array [200,40000] —— [每份尺寸, 总存储]。

5.4 存储增强（Storage Enhancements）

超过 8191 的定长数组由 jasshelper 自动拆成多个真实数组 + 换算函数实现，代价：

  • 数组读写从一次查表变成函数调用（JASS 中函数调用远慢于查表）；
  • 脚本体积显著膨胀（如 20 个成员 + 60000 索引 → 约 40 个新函数）；
  • jasshelper 内部上限：同一大数组最多拆 8 份 ≈ 408000 索引。
建议不需要大空间就不要写增强尺寸；≤8191 时无任何额外开销。可将尺寸定义成常量，让使用者决定是否启用增强。

5.5 key 类型

key 用于给每个声明生成唯一的整数常量，最典型用途是 hashtable 的键：

key
globals
    key AAAA
    private key BBBB
    public  key CCCC
    constant key DDDD  // 加 constant 仅为可读性
endglobals

private function test takes nothing returns nothing
    local hashtable ht = InitHashtable()
    call SaveInteger(ht, AAAA, BBBB, 5)
    call SaveInteger(ht, AAAA, CCCC, 7)
    call BJDebugMsg( I2S(BBBB) )  // 每个声明都是不同整数
endfunction

6. Struct 结构体

6.1 声明与成员

struct 基础
struct pair
    integer x=1
    integer y=2
endstruct

function pair_sum takes pair A, pair B returns pair
    local pair C=pair.create()
    set C.x=A.x+B.x
    set C.y=A.y+B.y
    return C
endfunction
  • 成员声明：类型 名字 [= 常量初始值]——初始值必须是编译期常量（不能调用 create()）；
  • struct 名即新类型，可用于 local、全局、参数、返回值；
  • struct 类型全局变量合法但不能直接初始化（pair p = pair.create() 非法），需在 init 中赋值；
  • 成员不能与已有的方法运算符（operator）重名。

6.2 创建与销毁

vJASS 没有 onCreate！这是官方手册确认的事实：create() 只做"分配索引 + 赋默认值"，不存在自动调用的构造回调。需要初始化逻辑时，标准做法是自定义 static method create（见下）。
方法性质说明
Name.create(args)static，可被自定义覆盖分配唯一索引并赋默认值；未自定义时直接转调 allocate
obj.destroy()
Name.destroy(obj)		实例/static 两用，可覆盖 0.9.Z.1+触发 onDestroy 后回收索引；对 0 调用无效果
allocate(args)private static仅拿索引不赋值；自定义 create 内部用它；继承链上参数须与父类 create 匹配
deallocate()private static 0.9.Z.1+仅回收索引；供自定义 destroy 调用
自定义 create（接管初始化）
struct vec
    real x
    real y
    real z

    // create 必须返回 struct 自身类型，参数任意
    static method create takes real ax, real ay, real az returns vec
        local vec r= vec.allocate()  // allocate 是 private，但 struct 内部可用
        set r.x=ax
        set r.y=ay
        set r.z=az
        return r
    endmethod
endstruct
实例上限 8190struct 底层是平行数组，索引 0 保留为 null，故每类型最多 8190 实例。超限时 create() 返回 0（debug 模式下编译会插入运行时警告）。可靠写法是检查 if (p == 0)。

6.3 this / thistype / 省略点语法

  • this：实例方法内指当前实例，本质是整数索引，只读；
  • 实例方法内可用单点 . 代替 this.：set .member = value；
  • thistype：struct 体内指代自身类型名的别名（等价于 struct 名），文本宏/模块场景下必备。
thistype
struct test
    thistype array ts
    method tester takes nothing returns thistype
        return thistype.allocate()
    endmethod
endstruct
// 等价于把 thistype 全部替换为 test

6.4 方法 method

  • 语法与函数一致（takes ... returns ...），可在任意位置调用（全局声明处除外）；
  • 实例方法内不要使用 waits、同步 native、GetTriggeringTrigger()（它们经 trigger 转发执行，其余事件响应可用）；
  • 静态方法 takes nothing 时可作为 code 值传给 TriggerAddAction 等：function something.bb。

6.5 静态成员与方法

static 成员
struct s
    integer a
    static integer b
endstruct

function test takes nothing returns nothing
    local s Yours = s.create()
    set Yours.a = 15   // 实例成员
    set s.b     = 30   // 静态成员按类型访问
    // set Yours.b = 30  // 错误：b 不是实例成员
endfunction

静态成员等价于 struct 命名空间内的全局变量，可有静态数组（static integer arr[10000]）。静态方法就是类方法：不使用实例，但能访问本 struct 的 private 成员。

6.6 封装与 readonly

struct 成员默认 public；private 成员仅 struct 声明内部可用；readonly 成员外部可读、内部可写（官方注明此为非标准特性）：

encapsulation
struct encap
    real a=0.0
    private real b=0.0
    public real c=4.5

    private method dosomething takes nothing returns nothing
        if (this.a==5) then
            set this.a=56
        endif
    endmethod

    static method altcreate takes real a, real b, real c returns encap
        local encap r=encap.create()
        set r.a=a
        set r.b=b              // struct 内部可用 private
        call r.dosomething()   // 同上
        return r
    endmethod
endstruct

6.7 运算符重载 operator

vJASS 允许重载的运算符仅限：<（自动派生 >）、自定义 ==、下标 []/[]=、属性 getter/setter。全部以 method operator 形式声明：

operator 全家福
struct operatortest
    string str=""

    method operator [] takes integer i returns string      // 读下标：1 个参数，必须有返回值
        return SubString(.str,i,i+1)
    endmethod

    method operator[]= takes integer i, string ch returns nothing  // 写下标：2 个参数
        set .str=SubString(.str,0,i)+ch+SubString(.str,i+1,StringLength(.str)-i)
    endmethod

    method operator< takes operatortest b returns boolean   // < 必须返回 boolean、参数同类型
        return StringLength(this.str) < StringLength(b.str)
    endmethod                                               // 声明 < 后 > 自动可用

    method operator size takes nothing returns integer      // 属性 getter：obj.size
        return StringLength(this.str)
    endmethod

    method operator size= takes integer v returns nothing   // 属性 setter：obj.size = x
        // 自定义赋值行为
    endmethod
endstruct
  • 自定义 == 后，!= 自动编译为 not(你的方法)；
  • 要比较"是不是同一个对象"（指针相等），必须 integer(a)==integer(b)；
  • []/[]=/属性 setter 可声明为 static 0.9.Z.1+，此时直接用类型名做下标；
  • setter 若返回 struct 自身类型，set obj.x = f(obj) 会编译成赋值链（少见但合法）；
  • 成员变量不能与 operator 同名。

6.8 onDestroy / onInit

onDestroy 是唯一的析构钩子（没有 onCreate）：声明了它的 struct 在 destroy() 时自动调用：

onDestroy 级联清理
struct sta
    real a
    real b
endstruct

struct stb
    sta H=0
    sta K=0

    method onDestroy takes nothing returns nothing
        if (H!=0) then
            call sta.destroy(H)
        endif
        if (K!=0) then
            call sta.destroy(K)
        endif
    endmethod
endstruct

继承场景下，销毁 C 实例会依次调用 C.onDestroy → B.onDestroy → A.onDestroy（子→父）。

static method onInit 在地图初始化时自动执行：

onInit
struct A
    static integer array ko

    private static method onInit takes nothing returns nothing  // 可 public 可 private
        local integer i=1000
        loop
            exitwhen (i<0)
            set A.ko[i]=i*2
            set i=i-1
        endloop
    endmethod
endstruct
初始化时序struct onInit 先于所有 library initializer 执行；struct 之间的相对顺序取决于脚本中的位置。0.A.2.A 起 module 的 initializer 先于 struct initializer 执行。

6.9 索引空间扩展 struct Name[N]

默认 8190 实例不够用时可显式扩容：

index space
struct X[10000]          // 请求 10000 个索引
    integer a
    integer b
endstruct

struct X2[10000]
    integer a[2]
    integer b[5]         // 数组成员消耗索引：实例数 ≈ 10000 / 5 = 2000
endstruct
  • [N] 不能与 extends 其他 struct/interface 同时使用（extends array [N] 除外 0.9.E.1+）；
  • 父 struct/interface 声明了 [N]，子类型自动继承同样的空间；
  • N > 8191 时启用存储增强，读写变慢（见 5.4）。

6.10 数组成员与数组 struct（extends array）

数组成员必须定长——不定长的 integer array v 成员不合法：

定长数组成员
struct stack
   private integer array V[100]     // 必须给出长度
   private integer N=0

   method push takes integer i returns nothing
      set .V[.N]=i
      set .N=.N+1
   endmethod

   method full takes nothing returns boolean
      return (.N==.V.size)          // 数组成员同样有 .size
   endmethod
endstruct
实例数换算数成员消耗索引空间：上限 = 索引空间 ÷ 最大数组成员长度。上例 8190 ÷ 100 → 约 80 个实例。多个数组成员时按最大的那个算。

数组 struct（extends array）是"只有成员语法的全局数组"，用于自管理索引的系统：

array struct
struct playerdata extends array
    integer a
    integer b
    integer c
endstruct

function init takes nothing returns nothing
    set playerdata[3].a=12        // 按索引直接用
    set playerdata[3].b=34
endfunction
  • 无 create/destroy/allocate、无默认值声明、无 onDestroy、不能有数组成员；
  • 所有索引"天然存在"，由使用者自行管理生命周期；
  • 大型系统的推荐写法：避开 onDestroy/stub 的 trigger 开销。

6.11 继承 extends / super / stub

struct 继承
struct A
   integer x
   integer y

   method setxy takes integer cx, integer cy returns nothing
       set this.x=cx
       set this.y=cy
   endmethod
endstruct

struct B extends A          // B 获得 A 的成员与方法
   integer z
   method setxyz takes integer cx, integer cy, integer cz returns nothing
       call this.setxy(cx,cy)
       set this.z=cz
   endmethod
endstruct

struct C extends B          // 支持链式继承
    ...
endstruct
  • allocate() 会沿继承链调用父类构造；若父类自定义了带参 create，子类 allocate 必须传同样的参数；
  • 父类 create 是 private → 禁止被继承；子类无法访问父类 private 成员；
  • onDestroy 按子→父顺序级联。

stub 方法 = 允许子类覆盖的方法，经 trigger 动态分发实现多态：

stub + super
struct Parent
    stub method xx takes nothing returns nothing
        call BJDebugMsg("Parent")
    endmethod

    method doSomething takes nothing returns nothing
        call this.xx()      // 运行时分发到实际类型的 xx
    endmethod
endstruct

struct ChildA extends Parent
    method xx takes nothing returns nothing
        call BJDebugMsg("- Child A -")
        call super.xx()     // super 强制调用父类版本
    endmethod
endstruct

function test takes nothing returns nothing
    local Parent A = ChildA.create()   // 父类变量持有子类实例
    call A.doSomething()
endfunction

6.12 接口 interface

interface 是 struct 的"行为契约"，实现 vJASS 的多态：

interface 基础
interface printable
    method toString takes nothing returns string
endinterface

struct singleint extends printable
    integer v
    method toString takes nothing returns string
        return I2S(this.v)
    endmethod
endstruct

function printmany takes printable a, printable b returns nothing
    call BJDebugMsg( a.toString()+" - "+b.toString() )   // 自动调用实际类型的方法
endfunction
特性规则
方法实现子 struct 必须全部实现接口方法，除非方法声明了 defaults
defaultsmethod f(...) returns T defaults 常量值——未实现时调用返回该常量（nothing 亦可）；仅支持常量
.exists布尔字段：if mi.myMethod1.exists then，探测 defaults 方法是否被子类型实现；static if 中同样可用
变量成员接口可声明变量，实现"伪继承"（子 struct 自动获得字段）
onDestroy禁止在 interface 中声明（自动拥有）；接口变量调用 .destroy() 会正确分发
运算符接口中可声明 method operator< 等，但不带签名；比较双方必须同类型，否则运行时中止（debug 编译会警告）
类型信息实例 .getType()（运行时整数）；类型 .typeid（编译期常量）
动态构造set a = myinterface.create(typeid) 按 typeid 创建；无效值返回 0；仅 takes nothing 的自定义 create 参与该机制
getType / typeid / 类型转换 / defaults
interface A
    integer x
endinterface

struct B extends A
    integer y
endstruct

struct C extends A
    integer y
    integer z
endstruct

function test takes A inst returns nothing
   if (inst.getType()==C.typeid) then        // 运行时类型 == 编译期常量
       set C(inst).z=5                        // 类型转换后再访问
   endif
   if (inst.getType()==B.typeid) then
       call BJDebugMsg("It was of type B with value "+I2S( B(inst).y ) )
   endif
endfunction

interface whattodo
    method onStrike takes real x, real y returns boolean defaults false
    method onFinish takes nothing returns nothing
endinterface

6.13 delegate 委托

delegate 是编译期的成员查找回退：本 struct 找不到的成员/方法，会到 delegate 成员的类型里找：

delegate
struct A
    private real x
    private real y

    public method performAction takes nothing returns nothing
        call DestroyEffect( AddSpecialEffect("path\\model.mdl", this.x, this.y) )
    endmethod
endstruct

struct B
    delegate A deleg                 // 声明委托成员

    static method create takes nothing returns B
     local B b = B.allocate()
        set b.deleg = A.create()     // 必须自行初始化委托对象
        return b
    endmethod
endstruct

function testsomething takes nothing returns nothing
    local B myB = B.create()
    call myB.performAction()          // 编译为 myB.deleg.performAction()
endfunction
  • 本 struct 成员优先于 delegate；多个 delegate 按声明顺序；
  • delegate 的方法不能用来满足 interface 的实现要求；
  • 访问 delegate 的 private 成员报"找不到成员"（而非 private 提示）。

6.14 module 模块

module 是"注入 struct 的代码包"——比文本宏高级：作用域感知、私有成员隔离、可调用宿主成员：

module / implement
module MyRepeatModule
    method repeat1000 takes nothing returns nothing
     local integer i=0
        loop
            exitwhen i==1000
            call this.sub()      // 调用宿主 struct 的方法（可以是 private）
            set i=i+1
        endloop
    endmethod
endmodule

struct MyStruct
    method sub takes nothing returns nothing
        call BJDebugMsg("Hello world")
    endmethod
    implement MyRepeatModule     // 注入模块
endstruct
  • implement optional 模块名：模块不存在时静默跳过；
  • 重复 implement 同一模块会被忽略；
  • module 的 private 成员对宿主不可见、不与宿主成员冲突；不允许 private operator；
  • module 内的 static method onInit（可 private）0.9.Z.1+：每个 implement 它的 struct 执行一次，可与 struct 自身 onInit 共存；
  • module 遵循其声明处 scope/library 的 private/public 规则；
  • module 中可使用 thistype（模块被注入哪个 struct，thistype 就指哪个 struct）。

7. 函数增强

7.1 函数即对象：.evaluate / .execute / .name

vJASS 函数拥有三个伪方法（静态方法同理）：

伪方法作用限制
.evaluate(args)可从声明处之上调用函数；带参传递、有返回值内部不能有 waits / 同步 native / GetTriggeringTrigger()；比普通调用慢
.execute(args)在新线程中执行（比 ExecuteFunc 快，参数直接传）同上；不返回值
.name返回函数的编译后名字字符串，喂给 ExecuteFunc 等系统—
互相递归 + 新线程
function A takes real x returns real
    if(GetRandomInt(0,1)==0) then
        return B.evaluate(x*0.02)    // B 在下方声明，必须 evaluate
    endif
    return x
endfunction

function B takes real x returns real
    if(GetRandomInt(0,1)==1) then
        return A(x*1000.)
    endif
    return x
endfunction

function test takes nothing returns nothing
    call DestroyEffectAfter.execute(f,3.0)   // 新线程，函数内可以有 wait
endfunction

scope test
    public function xxx takes nothing returns nothing
        call BJDebugMsg(xxx.name)            // 输出 "test_xxx"
    endfunction
endscope
方法的自上引用0.9.Z.1+ 从声明处之上调用方法必须写 .evaluate()，否则语法错误（可在 jasshelper.conf 加 [automethodevaluate] 恢复旧行为）。该特性不适用于 common.j / blizzard.j 的函数。

7.2 函数接口 function interface

vJASS 的函数指针：

function interface
function interface realfunc takes real x returns real

function double takes real x returns real
    return 2*x
endfunction

function repeater3 takes real x, realfunc F returns real
    set x=F.evaluate(x)
    set x=F.evaluate(x)
    set x=F.evaluate(x)
    return x
endfunction

function test takes nothing returns nothing
    local real x = repeater3( 2.0, double)        // 裸函数名直接当值传
    local realfunc fun = realfunc.double          // 或 接口名.函数名 取指针
    call BJDebugMsg(R2S(repeater3(1.0, fun)))
endfunction
  • 类型一致的静态方法也可当函数指针：set mf = try.AAAA；
  • 非静态方法也能转换：它被视为"多出一个首参 integer（实例）"的函数，调用时显式传入实例：call mf.evaluate(ts)；
  • 函数指针可 integer() 转整数存储、再转回原接口类型。

8. 编译期控制

8.1 static if

条件只含常量布尔、and、not（支持括号、elseif），编译期求值，不满足的分支直接从脚本中删除：

static if
globals
    constant boolean DO_KILL_LIB = true
endglobals

function fun takes nothing returns nothing
    static if DO_KILL_LIB and LIBRARY_UnitKiller then
        call UnitKiller(GetTriggerUnit())
    else
        call KillUnit(GetTriggerUnit())
    endif
endfunction

可用条件源：LIBRARY_库名 常量、struct 静态常量布尔、thistype、方法的 .exists。

8.2 debug 与 DEBUG_MODE

JASS 隐藏特性：以 debug 开头的语句行，在非 debug 模式编译时被 jasshelper 整行移除：

debug
function Something takes integer a returns nothing
   debug call BJDebugMsg("a is "+I2S(a))
   call KillNUnits(a)
endfunction

同时提供编译期常量 DEBUG_MODE（true/false），可配合 static if 使用。

8.3 hook 钩子

监听 native / blizzard.j 函数被调用（可捕获参数）：

hook
function onRemoval takes unit u returns nothing
    call BJDebugMsg("unit is being removed!")
endfunction

struct err
    static method onrem takes unit u returns nothing
       call BJDebugMsg("This also knows that a unit is being removed!")
    endmethod
endstruct

hook RemoveUnit onRemoval
hook RemoveUnit err.onrem
限制若某个 bj 函数在内部调用了被 hook 的函数，经由该 bj 函数的调用不会触发 hook。

9. 文本宏 Text Macros

编译期文本复制替换：//! textmacro 定义、//! endtextmacro 结束、//! runtextmacro 展开：

textmacro
//! textmacro Increase takes TYPEWORD
function IncreaseStored$TYPEWORD$ takes gamecache g, string m, string l returns nothing
    call Store$TYPEWORD$(g,m,l,GetStored$TYPEWORD$(g,m,l)+1)
endfunction
//! endtextmacro

//! runtextmacro Increase("Integer")
//! runtextmacro Increase("Real")
// 展开得到 IncreaseStoredInteger / IncreaseStoredReal 两个函数
  • 参数占位符用 $参数名$（因为常要与其他符号相连）；
  • 字符串与注释不豁免——只要匹配 $ARG$ 就会被替换；
  • 无参数宏省略 takes；调用可写 //! runtextmacro bye() 或 //! runtextmacro bye；
  • textmacro_once：同 library_once，重复定义忽略；
  • //! runtextmacro optional 名字(args)：宏不存在时不报错；
  • 宏常与 scope/library 组合生成"静态类"（宏里包 scope，展开成多个带前缀的模块）。

指令作用

11. vJASS 与 Zinc 的边界

jasshelper 同时支持 Zinc（花括号风格、更简洁严格）。网上大量"vJASS 教程"把 Zinc 特性混进 vJASS，以下按官方手册目录逐项区分：

特性vJASSZinc
块结构if/endif、loop/endloop（JASS 风格）{ } + ;
if / while / for / break仅 JASS 原生形式（无 for/break）全部支持（for 有 range 与 C 两种形式）
逻辑运算符and / or / not另有 && / || / !
复合赋值无 += -= *= /=有
匿名函数 / 匿名方法无有
函数指针function interfacetype X extends function(...)
static if / debug✅ 都有✅ 都有
struct / library / 文本宏✅有对应物（语法不同）
高频讹传澄清（均经官方手册确认）：
  • vJASS 没有 onCreate —— 构造逻辑写在自定义 static method create 里；
  • vJASS 没有 &&、||、!、+=、for、break；
  • struct 不定长数组成员非法，必须给长度（或改用动态数组类型成员）；
  • struct 实例上限是 8190（不是 8191）；数组上限是 8191。

12. 限制与性能备忘

项数值 / 规则
JASS 数组索引上限8191（struct 实例因保留索引 0 为 null，为 8190）
二维数组实际尺寸上限≈ 40800（宽×高）
存储增强内部上限单数组最多拆 8 份 ≈ 408000 索引；>8191 后读写退化为函数调用
方法内禁用waits、同步 native、GetTriggeringTrigger()（其余事件响应可用，但不推荐）
initializer 要求必须 takes nothing；library 走 ExecuteFunc（独立线程），scope 走普通 call
初始化顺序struct onInit → module initializer（每个 struct 一次）→ struct initializer → library initializer（按依赖序）
函数内联优化0.9.A.0 起默认开启（单行函数、参数各求值一次）；debug 模式或 --nooptimize 关闭
标识符避免连续双下划线 __（预处理器生成名专用）
销毁纪律不再使用的实例必须 destroy；悬垂引用（用已销毁索引）与重复 destroy 是两大运行时隐患
